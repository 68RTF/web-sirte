# Как запустить и задеплоить NOVA

## Запуск на компьютере

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Открой адрес, который появится в терминале.

## Самый простой деплой — Vercel

1. Создай новый репозиторий на GitHub и загрузи в него эту папку.
2. Зайди на [vercel.com](https://vercel.com) через GitHub.
3. Нажми **Add New → Project** и выбери репозиторий.
4. Vercel сам определит Next.js. Нажми **Deploy**.

Если открылся экран ручных настроек:

- **Application Preset:** Next.js
- **Root Directory:** `./`
- **Build Command:** оставить стандартным или указать `npm run build`
- **Output Directory:** оставить пустым
- **Install Command:** оставить стандартным или указать `npm install`
- **Environment Variables:** ничего не добавлять

В проект уже добавлен файл `vercel.json`, поэтому обычно эти параметры
подставятся автоматически.

После этого Vercel выдаст бесплатную ссылку вида `название.vercel.app`. При каждом новом `git push` сайт будет обновляться автоматически.

## Проверка перед публикацией

```bash
npm run build
```

## Где менять товары

Товары находятся в массиве `products` в файле `app/page.tsx`. Изображения лежат в папке `public`.

Это демонстрационный магазин: корзина работает в браузере, но настоящая оплата и база данных не подключены.
